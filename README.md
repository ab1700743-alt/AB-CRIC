# AB Cricket

**Established by:** Syed Abdul Basit

AB Cricket is an Android cricket scoring and statistics application.

## Planned features
- Live match scorecards
- Match history
- Batting and bowling statistics
- Player profiles and career records
- Weekly, monthly, yearly, and all-time rankings
- Tournaments and leaderboards
- Admin-only match and score management

## Technology
- Android application
- Supabase backend for cloud data and synchronization

## Project status
Initial project setup. More application files and features will be added as development progresses.
